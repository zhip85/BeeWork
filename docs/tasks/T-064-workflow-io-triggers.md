# T-064 Workflow 输入输出、触发方式与试运行

**版本**：V0.2　**依赖**：T-062、T-028、T-002　**PRD**：3.3.8–3.3.10、AGT-028（Workflow 规则）、NFR-017、5.7

## 范围

1. 输入输出（3.3.8）：两张字段表、默认字段、字段名校验（小写下划线、不重复）、类型、必填、说明、默认值（定时触发需要）；JSON Schema 实时预览；运行时按 Schema 校验输入，缺失必填时首个节点失败并显示「缺少 {字段}」。
2. 触发方式（3.3.9）：
   - API：开放接口 `POST /v1/workflows/{id}/runs`（同 T-028 的鉴权与限流）。**开发负责人决定**：API 密钥权限范围新增 `workflows.run`（SET-090 的范围列表加一项）。同步模式等待结果（默认超时 30 秒），异步模式返回 run_id 并可查询。
   - 定时：5 段 cron + 时区（4 个选项）+ 预设；Worker 调度器按工作流登记到期任务（幂等键 `workflow:{id}:{计划时间}`）；必填字段无默认值时不允许开启。
   - 作为工具：工具名（默认由名称转换，无法转换时 `run_workflow`）、调用时机；注册到能力目录，供 Agent、Chatflow 调用，输入字段即参数。
3. 试运行（3.3.10）：按字段生成表单、运行当前草稿、节点时间线（耗时或跳过）、输出 JSON、失败原因；`source=trial`，扣点，在调用追踪中标记为试运行。
4. 生产运行只用可用配置。

## 验收标准

- [ ] 测试：cron 校验、调度幂等（同一计划时间只运行一次）、必填缺失失败、API 范围缺 `workflows.run` 时 403、跨租户 404。
