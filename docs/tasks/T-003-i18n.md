# T-003 前端中英双语框架

**阶段**：1　**依赖**：无　**PRD**：GLB-023、GLB-085、GLB-086、NFR-014

## 目标

现在就建立 i18n 框架，后续所有新页面直接使用字典，避免 V1.0 时全站返工。

## 范围

1. 引入 `i18next` + `react-i18next`（锁定具体版本）；字典放 `frontend/src/i18n/zh-CN/*.json`、`frontend/src/i18n/en/*.json`，按领域分命名空间（`common`、`nav`、`auth`、`members`、`platform`、`settings`、`audit`、`enums`）。
2. 语言来源顺序：用户偏好（后端）→ 浏览器 `localStorage` → `zh-CN`。后端新增 `users.locale`（`zh-CN`/`en`）与 `PATCH /api/v1/auth/me/preferences`；`/auth/me` 返回 `locale`。
3. 顶栏语言切换（EN / 中），切换即时生效并保存偏好（GLB-023）。
4. 枚举与状态值统一走 `enums` 命名空间（租户状态、套餐、区域、角色、模型类型、网关同步状态等），替换 `constants.ts` 中的中文映射。
5. 时间与数字格式化工具：相对时间（列表）、租户时区完整时间（详情）、`18.2k`/`2.48M` 缩写、百分比 1 位小数（GLB-086）。
6. **迁移范围**：应用外壳（侧栏、顶栏、导航）、登录页、邀请页、无权限页全部改用字典；其他已有页面可分批迁移，但本任务至少完成上述范围，并在字典中补齐其英文。
7. 增加检查脚本（`npm run i18n:check`）：两种语言 key 集合一致，CI 中执行。

## 验收标准

- [ ] 切换语言后外壳与登录页全部变为英文，刷新后保持。
- [ ] `i18n:check` 在 CI 中运行并通过。
- [ ] `docs/architecture.md` 第 4 节补充“如何新增文案”的说明。

## 不在范围

- 后端错误信息的多语言（后端返回 `code`，前端按 code 映射，属于后续逐步迁移）。
