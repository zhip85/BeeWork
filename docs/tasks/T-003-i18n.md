# T-003 前端中英双语框架

**阶段**：1　**依赖**：无　**PRD**：GLB-023、GLB-085、GLB-086、NFR-014

## 目标

现在就建立 i18n 框架，后续所有新页面直接使用字典，避免 V1.0 时全站返工。

## 范围

1. 引入 `i18next` + `react-i18next`（锁定具体版本）；字典放 `frontend/src/i18n/zh-CN/*.json`、`frontend/src/i18n/en/*.json`，按领域分命名空间（`common`、`nav`、`auth`、`members`、`platform`、`settings`、`audit`、`enums`）。
2. 语言来源顺序：用户偏好（后端）→ 浏览器 `localStorage` → `zh-CN`。后端新增 `users.locale`（`zh-CN`/`en`）与 `PATCH /api/v1/auth/me/preferences`；`/auth/me` 返回 `locale`。
3. 顶栏语言切换（EN / 中），切换即时生效并保存偏好（GLB-023）。
4. 枚举与状态值统一走 `enums` 命名空间（租户状态、套餐、区域、角色、模型类型、网关同步状态等），替换 `constants.ts` 中的中文映射。
5. 时间与数字格式化工具：相对时间（列表）、租户时区完整时间（详情）、`18.2k`/`2.48M` 缩写、百分比 1 位小数（GLB-086）。
6. **迁移范围**：应用外壳（侧栏、顶栏、导航）、登录页、邀请页、无权限页全部改用字典；其他已有页面可分批迁移，但本任务至少完成上述范围，并在字典中补齐其英文。
7. 增加检查脚本（`npm run i18n:check`）：两种语言 key 集合一致，CI 中执行。

## 验收标准

- [ ] 切换语言后外壳与登录页全部变为英文，刷新后保持。
- [ ] `i18n:check` 在 CI 中运行并通过。
- [ ] `docs/architecture.md` 第 4 节补充“如何新增文案”的说明。

## 不在范围

- 后端错误信息的多语言（后端返回 `code`，前端按 code 映射，属于后续逐步迁移）。

## 完成记录

**改动文件**
- 后端：`models/__init__.py`（`User.locale`）、`schemas/__init__.py`（`CurrentUserResponse.locale`、`UserPreferencesRequest`）、`api/auth.py`（`PATCH /auth/me/preferences`）、`api/common.py`、迁移 `0014_user_locale.py`（可降级）、`tests/test_tenant_auth.py`。
- 前端：新增 `src/i18n/`（`index.ts`、`format.ts`、`LanguageSwitch.tsx`、两种语言 8 个命名空间 JSON）、`scripts/check-i18n.mjs`；修改 `App.tsx`、`main.tsx`、`api.ts`、`roles.ts`、`types.ts`、`App.css`、登录/邀请/无租户页、`SectionPlaceholder`、`PlatformConsole` 及用到枚举的 4 个页面；删除 `constants.ts`。
- 其他：`.github/workflows/ci.yml` 增加 `i18n:check`；`docs/architecture.md` 第 4 节补“如何新增文案”。

**迁移 / 接口**：`0014_user_locale`（`users.locale`，可空）；`PATCH /api/v1/auth/me/preferences {locale: "zh-CN"|"en"}`，需登录与 CSRF，非法值 422，变更写审计；`/auth/me` 与登录响应返回 `locale`。

- `docker compose exec web sh -c "npx tsc -b && npm run lint && npm run i18n:check && npm run build"`：通过。
- 网关 e2e：本任务不涉及，未运行。未连接任何真实第三方引擎。
- **未做浏览器目视验证**：切换后外壳/登录页变英文、刷新保持，仅由代码路径与构建保证，建议验收时手动点一遍。

**遗留问题**
- 偏好接口无租户概念，只有 403（缺 CSRF）与 422 测试；“跨租户 404”不适用。
- `members`/`settings`/`audit` 命名空间为空；Dashboard、MembersPage、AuditLogPage、设置页、平台各页正文、`CreateModal` 仍是中文。
- `App.tsx` 中会话过期判断仍依赖后端中文错误文案（`请先登录` 等），待后端错误按 `code` 映射时一并改。
- 登录前切换语言只存在 `localStorage`；登录后若 `users.locale` 为空，沿用浏览器当前语言，不会自动回写。
- 偏好保存失败时静默忽略（浏览器已生效）。
