# T-080 实时会话、会话详情、反馈与质量分

**版本**：V0.3　**依赖**：T-026、T-054、T-084　**PRD**：3.8 总述、3.8.1（OPS-001–005）、AST-023 赞踩反馈、AST-072、GLB-087、8.3#18

## 范围

1. 会话列表（OPS-001–002）：搜索（用户 / 会话 ID）、助理多选、时间范围、渠道与状态筛选、状态条计数；按最近活动倒序；运行中每 10 秒刷新；数据按租户、成员的组织/助理范围、顶栏环境过滤。状态：运行中 / 转人工 / 已解决 / 已放弃（已放弃 = 用户未得到回复即离开，OPS-005）。
2. 侧栏预览（OPS-003）：最新用户问题、本轮各 OC 阶段的结果与耗时（来自 run 事件 / 阶段 span）、“打开完整调用链”（T-084 详情）。
3. 会话详情（OPS-004）：完整对话（组件按渲染效果、按合规设置与查看人权限脱敏）、每条助理消息可展开调用链、用户信息、会话元数据（渠道、助理版本、起止时间、轮数、Token、点数、CSAT）、用户记忆（可删除，调用 T-056）。操作入口：人工介入（T-081）、标注（T-082）、加入评测集/测试用例（T-083/T-027）、导出（T-086）。
4. 赞踩反馈（AST-023）：网站/H5/开放 API 增加对单条回复的反馈接口；会话 CSAT = 赞 / (赞 + 踩)。
5. 质量分（OPS-005，**8.3#18 暂定算法，待校准**）：会话结束后入队，用租户默认对话模型对“理解准确 / 回答有据 / 是否解决”各打 0–100，等权平均；评分 prompt 与权重放配置，可替换；运行中显示“—”。评估调用 `source=eval_auto`，计入点数。
6. 回填 T-020 助理统计中的“月会话量”。

## 权限

运营 · 实时会话（6.1）：所有角色可查看；租户管理员与运营可人工介入与导出。平台管理员不能读取会话内容（PER-011）。

## 验收标准

- [ ] 测试：组织范围外的会话不出现；跨租户详情 404；查看者看到脱敏内容；环境过滤生效。
- [ ] 质量分任务幂等（同一会话只评一次）且模型可替换（假模型测试）。
