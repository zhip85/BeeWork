# T-127 增强 / 独享隔离与多区域部署

**版本**：V1.0　**依赖**：T-124、T-120　**PRD**：NFR-006、NFR-007、PLT-020 第 4 步隔离等级与区域、PLT-032 迁移申请

## 问题（阻塞，需要架构决策）

technical-plan 的阻塞决策“是否需要增强/专属隔离（NFR-006）及多区域部署拓扑（NFR-007）”尚未定。需要决定：

1. 增强隔离的落地方式：每租户独立 PostgreSQL 数据库（同实例 / 独立实例）、独立 RAGFlow 实例或账号、独立 LiteLLM？
2. 独享隔离：独立集群的交付方式（同一控制面管理多个数据面，还是完全独立部署）。
3. 区域拓扑：每区域一套完整部署 + 全局平台控制面，还是全局单控制面 + 区域数据面；平台运营后台如何跨区域聚合。
4. 租户迁移（区域 / 隔离等级变更）的停机窗口与工具。

## 决策后的实现范围（预案）

- 租户数据源路由（按隔离等级选择数据库连接）、区域路由（请求入口按租户区域转发）、迁移工具与 Runbook、跨区域平台聚合接口。
