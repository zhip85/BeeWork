# T-044 H5 渠道

**版本**：V0.3　**依赖**：T-041、T-042、T-043　**PRD**：3.7.1 H5、CHN-026（访问链接与二维码）、NFR-015

## 范围

1. H5 适配器：连接参数 H5 路径（租户内唯一）与允许域名；访问地址 `https://{子域名}.beework.ai/h5/{路径}`（本地开发为 API 静态路由）。
2. H5 页面：独立轻量构建（与 T-040 的 `widget.js` 共用对话核心与组件渲染器），移动布局、全屏/底部抽屉入口、流式输出；终端用户会话令牌机制同 T-040。
3. 接入代码：访问链接 + 二维码（前端生成）。
4. 兼容性：iOS 15+、Android 9+ 主流浏览器（NFR-015），用 Playwright 移动视口跑主流程。

## 验收标准

- [ ] 非允许域名嵌入（iframe）被拒；路径冲突 409。
- [ ] Playwright 移动视口：打开 → 发送消息 → 收到流式回复 → 组件渲染。
