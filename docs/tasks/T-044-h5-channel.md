# T-044 H5 渠道

**版本**：V0.3　**依赖**：T-041、T-042、T-043　**PRD**：3.7.1 H5、CHN-026（访问链接与二维码）、NFR-015

## 范围

1. H5 适配器：连接参数 H5 路径（租户内唯一）与允许域名；访问地址 `https://{子域名}.beework.ai/h5/{路径}`（本地开发为 API 静态路由）。
2. H5 页面：独立轻量构建（与 T-040 的 `widget.js` 共用对话核心与组件渲染器），移动布局、全屏/底部抽屉入口、流式输出；终端用户会话令牌机制同 T-040。
3. 接入代码：访问链接 + 二维码（前端生成）。
4. 兼容性：iOS 15+、Android 9+ 主流浏览器（NFR-015），用 Playwright 移动视口跑主流程。

## 验收标准

- [ ] 非允许域名嵌入（iframe）被拒；路径冲突 409。
- [ ] Playwright 移动视口：打开 → 发送消息 → 收到流式回复 → 组件渲染。

## 完成记录

分支 `task/T-044-h5-channel`。**无迁移**。

**后端**
- 访问地址：`{PUBLIC_API_URL}/h5/{租户标识}/{路径}`（本地开发为 API 静态路由；规格里的 `https://{子域名}.beework.ai/h5/{路径}` 需要泛域名与反向代理，没有做，租户标识放在路径里代替子域名）。H5 页面由 `api/h5.py` 提供：一个很小的 HTML（移动视口、`noindex`、`no-store`），加载与网站挂件**同一个 `widget.js`**（`data-h5="租户/路径"`），所以对话核心、流式、组件渲染器、访客令牌都是共用的，不是另做一套。
- 访问控制：H5 页面由 API 自己提供，页面发出的请求来自 API 自己的 Origin。会话接口 `POST /v1/h5/session` 只接受来自本站 Origin 的请求（其他 403），按租户标识 + 路径找到已发布且启用 / 异常的 H5 渠道，签发与网站挂件同样的访客令牌（绑定渠道、访客、来源）；之后的对话与读消息沿用 `/v1/widget/chat`、`/v1/widget/conversations/…`，渠道类型决定来源（会话来源记为 `h5`）。**渠道里的“允许域名”对 H5 的含义是“可以把这个页面用 iframe 嵌进去的网站”**：页面响应带 `Content-Security-Policy: frame-ancestors 'self' <允许域名…>`，其他站点嵌入会被浏览器拒绝；直接打开链接不受限。停用渠道后令牌立即失效（403）。
- 连接参数：H5 路径规范化为一个前导 `/`、无末尾 `/`；只能含字母、数字和 `. _ ~ / -`，不能只有 `/`；**租户内唯一，冲突 409 `channel.h5_path_taken`**（不同租户可以用同一路径，因为地址里有租户标识）；发布前仍须至少一个允许域名。接入代码：访问链接 + iframe 嵌入片段。
- 体验：会话接口把渠道快照冻结的全部体验项（主题、圆角、入口形式、欢迎语、各开关、流式）交给页面。

**前端 / 页面脚本**：`widget.js` 升到版本 3，新增 H5 模式（全屏或底部抽屉、整页即对话、无悬浮按钮、自动打开、16px 输入框与安全区适配），并开始**消费 T-042 的体验项**：圆角、深色 / 自动主题、网站挂件的左下角、流式输出关闭时整段一次显示、表格关闭时把 Markdown 表格转成列表、卡片 / 表单开关决定哪些组件显示。渠道页的接入代码弹窗显示 H5 链接与 iframe 片段，并说明哪些网站可以嵌入。

**验证**：ruff；`test_h5` 10 项（路径规范化 / 租户内唯一 / 跨租户可同名、发布前检查、接入代码、页面内容与 `frame-ancestors`（只有允许域名）、未发布 / 停用 / 他租户 / 网站渠道的页面 404、会话携带冻结的体验、会话只接受本站 Origin（无 Origin、嵌入方、第三方都 403）、经 H5 令牌完成一次对话并记为 `h5`、令牌不能在别的站点重放、停用后立即 403）；`scripts/check_h5_page.mjs`（jsdom 里跑真实 `widget.js`：H5 模式走 `/v1/h5/session`、全屏 / 抽屉 / 深色 / 圆角、流式关闭、表格转列表、卡片 / 表单开关、网站挂件行为不变）；`scripts/check_widget_components.mjs` 仍通过；T-040 / T-041 / T-042 测试里随体验项扩展更新了两条断言；全量后端（sqlite）1496 项通过、跳过 26 项；前端 tsc / lint（仍是原有 9 条警告）/ i18n / style / build；开发库里的真实 API 已提供新页面与会话接口（对不存在的页面 404、会话 `site_not_found`）。
