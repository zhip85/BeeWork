# T-085 工作台真实指标与助理表现报告

**版本**：V0.3　**依赖**：T-080、T-011、T-082　**PRD**：3.1（DSH-001–042）、AST-051、AST-053、GLB-086、GLB-087、8.3#19

## 范围

1. 日汇总表 `daily_assistant_stats`（日 × 租户 × 环境 × 组织 × 助理：会话数、已结束、已解决、转人工、放弃、活跃终端用户数、点数、平均首字延迟、调用量、成功率）由 Worker 每 10 分钟增量刷新当日、每日凌晨重算前一日；活跃用户用当日去重集合再汇总（跨天去重在查询时对明细计算，范围 ≤ 1 年）。
2. 工作台（DSH-001–013、020–021、030–033、040–042）：问候语按租户时区、筛选（组织树 / 助理 / 时间范围）与联动、指标卡与环比（上一周期无数据显示“—”）、60 秒自动刷新、柱状/折线图（> 31 天按周）、快捷操作按权限显示、热门助理前 5、最近动态（来自审计事件中的指定类型）。
3. 助理表现报告页（DSH-022）：继承筛选、按天明细 + 按助理汇总、导出 CSV。
4. 助理概览指标行与 14 天趋势（AST-051、AST-053）。
5. 替换工作台目前的静态示例数据（Dashboard.tsx 中的硬编码值）。

## 验收标准

- [ ] 汇总任务幂等且与明细一致（测试：同一数据重算两次结果相同；汇总值等于明细直接聚合）。
- [ ] 测试：无权限组织的数据不计入；环境过滤生效。
- [ ] 列表/指标接口 P95 < 500 ms（NFR-002，1 年数据量的测试数据）。
