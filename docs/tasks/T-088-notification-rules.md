# T-088 通知规则与外部通道

**版本**：V0.3　**依赖**：T-087、T-008、T-023　**PRD**：3.10.11（SET-100–102）、5.8、SET-082 告警接收人
**外部条件**：短信通道需要短信服务商账号（无账号时 SMS 通道显示“未配置”，不可选）

## 范围

1. 通知规则（SET-100–101）：事件（12 种：发起审批、审批结果、护栏触发、转人工请求、转人工超时、预算阈值、配额阈值、评测完成、渠道异常、MCP 连接异常、密钥即将过期、安全事件）、通道（邮件 / Slack / SMS / Webhook）、接收人（成员 / 角色 / 邮箱；Slack 为 Incoming Webhook 地址并做公网 https 校验；SMS 为手机号）、频率（实时 / 每小时汇总 / 每日汇总）、状态。
2. 分发：订阅 T-087 的事件总线；汇总频率由 Worker 定时合并发送；邮件经 T-008；Slack 经 T-071 安全出站客户端；SMS 适配器接口 + 一个服务商实现（选型由开发负责人在开工时确认）。
3. 站内通知（SET-102）：审批待办、评测完成、预算告警无论是否配置规则都进入通知中心（T-023 已有调用的保持，缺的补齐）。
4. 尚未发出事件的模块（护栏触发、渠道异常、MCP 异常、密钥即将过期、安全事件）在各自任务中调用 `emit_event`；本任务把事件类型与中英文文案定义齐全。

## 验收标准

- [ ] 测试：汇总频率把同一小时内的多条事件合并为一封；停用规则不发送；接收人为角色时按当前成员解析；跨租户事件不会发给其他租户成员。
