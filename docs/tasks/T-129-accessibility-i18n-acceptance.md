# T-129 无障碍与国际化全量验收

**版本**：V1.0（发布门禁）　**依赖**：各页面模块完成后　**PRD**：NFR-014、NFR-015、NFR-016、GLB-085、8.4

## 范围

1. 无障碍（WCAG 2.1 AA）：Playwright + axe 对全部页面扫描；键盘可达、焦点可见、图标按钮 aria-label、对比度；网站/H5 渠道组件同样检查。问题按页面修复。
2. 国际化：`i18n:check` 覆盖全部命名空间；修正 8.4 列出的未翻译与错误翻译；状态词按字典统一；后端错误 `code` → 前端文案映射完成（T-003 遗留）。
3. 终端用户侧语言：网站/H5/组件渲染器支持租户启用的语言（简中、英文、日文、繁中）。
4. 浏览器兼容（NFR-015）：最新两版 Chrome/Edge/Safari/Firefox 冒烟，最小宽度 1280 px。

## 验收标准

- [ ] axe 扫描 0 个严重/重要问题（CI 中运行）；8.4 清单逐项勾选；兼容性冒烟记录。
