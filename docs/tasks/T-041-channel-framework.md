# T-041 渠道框架完整版：渠道类型、实例向导、发布与接入代码

**版本**：V0.3　**依赖**：T-040、T-028、T-010　**PRD**：3.7.1–3.7.4（CHN-001–026）、3.7.7（CHN-050–051）、3.15.1（PLT-100–102）、5.1 渠道实例状态机、RUL-003、8.3#8

## 目标

把 T-040 的“只有网站”的最小渠道，扩展为五种类型共用的渠道框架；具体渠道的适配器由 T-044–T-046 实现，开放 API 复用 T-028。

## 范围

1. 平台渠道类型（PLT-100–102）：`channel_types`（编码、名称、连接参数定义、渲染能力标签、版本号、启用状态、平台默认体验）；平台可启用/停用（停用后租户不可新建，已有实例不受影响）；不提供“新建类型”。套餐未包含的类型（如标准版的 IM 渠道）显示“套餐未开通”（CHN-051）。
2. 适配器接口 `ChannelAdapter`：`validate_connection(config)`、`health_check(instance)`、`render(message, snapshot)`（按能力开关把表格转列表、关闭流式等，CHN-035）、`integration_snippet(instance)`；网站与开放 API 先实现，其余类型由后续任务注册。
3. 实例向导完整版（CHN-010–011）：五种类型、类型切换重置、已发布不可改类型、环境（开发/预发用助理最新草稿，生产用线上版本）、动态连接配置（密钥类加密 + 掩码，SDK Key / API Key 平台生成且可重置）、组件选择（T-043 后接入）、快速体验覆盖、实时预览。
4. 列表（CHN-001–004）与行操作（停用/启用、获取接入代码、删除）。
5. 发布（CHN-020–026）：弹窗三个页签（组件清单 diff、注入提示词（T-059 函数）、试跑（真实 schema 校验））、确认发布生成不可变快照（版本号 +0.1、组件定义、体验生效值）、接入代码；首次发布与连接参数变更受“接入新的外部渠道”审批策略约束；发布前校验连接配置完整与助理可用。
6. **8.3#8 产品决策（按 PRD 建议执行）**：体验配置修改须重新发布才对线上生效。
7. 健康检查：Worker 定期调用适配器，持续失败置“异常”并通知（5.8），恢复后置回启用。

## 验收标准

- [ ] 测试：快照不可变（触发器）；组件被修改后已发布快照不变且列表显示“有未发布修改”（CHN-025）；停用类型后新建 403；套餐未开通 403。
- [ ] T-040 的网站渠道迁移到新框架后原有验收测试仍通过。
