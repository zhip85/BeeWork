# T-061 智能体编辑器补全与工具调用运行时

**版本**：V0.2　**依赖**：T-070、T-071、T-033　**PRD**：演进 PRD 6.2（Agent）、6.4、6.6、7.6、9.4 第 7 步；原 PRD AST-021、RUL-014
**外部条件**：供应商模型 Key（真实验收需要）

> **2026-11-10 需求变更**：演进 PRD 取消独立的“助理”概念，智能体 = 现有助理（`assistants` 表、详情页、OC、渠道、版本）。原规格中“`agents` 表里的 Agent 编辑器”与“助理驱动方式（driven_by）”作废：不再有“助理由某个 Agent 驱动”，智能体自己就是执行者。多智能体协作见 T-066。

## 编辑器补全（在现有智能体详情页“基础”“能力”中实现）

1. 身份与指令（演进 PRD 6.4）：在现有名称、简介、提示词、默认语言之外增加**角色**（一句话）与**回答风格**（简洁 / 均衡 / 详细，默认均衡）。
2. 模型：主模型（已有）+ **备选模型**（主模型调用失败或被停用时使用，只能选租户已启用的对话模型）+ 温度（0–2，默认 0.7）+ 最大输出 token（1–模型上限，默认按模型）。配置存 `draft_config`（新增字段带默认值，旧数据可读，不需要迁移），随版本快照冻结。
3. 能力：挂载选择器支持 T-070 注册的全部类型（知识库、Skill、MCP、API 插件、Chatflow 连接、Workflow 连接、叶子智能体（T-066））；每项挂载可配**允许的工具 / 操作**（最小权限，演进 PRD 7.6、15.3）与**委派描述**（何时调用）。失效挂载红色显示并计入配置检查。
4. 移除“驱动方式”字段的界面与 `driven_by` 的使用（字段保留可读，不再写入；在 development-status 记录）。

## 工具调用运行时

- 现有 `execute` 阶段从“单次 LLM 调用 + 检索”升级为 LangGraph **工具调用循环**：可用工具 = 挂载知识库的检索工具（T-033）+ 挂载能力的具体工具（经 T-071 执行器）+ 挂载的流程连接（T-075）+ 叶子智能体（T-066，作为子调用）。工具描述取挂载项的委派描述。
- 约束：最大迭代次数（默认 8）、总超时（默认 60 秒）、调用深度上限（演进 PRD 6.7 只允许一层协作，深度实际 ≤ 2；超限返回错误给模型）。
- 备选模型：主模型返回错误或不可用时切换一次，trace 记录切换原因。
- 线上运行用冻结的版本快照；测试控制台用草稿（`source=debug`）。
- 每次工具调用一个 Langfuse span；工具结果仍经 OC 输出网关。

## 验收标准

- [ ] 单元测试（假模型）：工具调用循环、迭代上限、超时、工具不在挂载列表或未勾选时拒绝执行、备选模型切换。
- [ ] 测试：新增配置字段对旧草稿与旧版本快照兼容（读取时补默认值）。
- [ ] 真实模型跑通一次“智能体调用知识检索后回答”（有 Key 时），记录在 development-status。
