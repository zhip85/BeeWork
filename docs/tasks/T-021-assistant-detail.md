# T-021 助理详情、草稿编辑与配置检查

**阶段**：3　**依赖**：T-020　**PRD**：3.2.3（AST-040–045）、3.2.4（AST-050–052）、3.2.5、5.4 引用完整性

## 范围

1. 详情页框架：页头（身份区、状态、版本、更多菜单）、8 个页签。本任务实现“概览”“能力”两个页签；“版本”（T-024）、“测试用例”（T-027）、“会话记录”（T-026）、“渠道”（T-040/T-028）、“编排”（T-054）、“依赖”（T-070）先显示“即将开放”占位并在看板备注。
2. 概览：配置路径（AST-050）、基础配置（AST-052，含“查看完整提示词”弹窗）；指标行与表现图在 T-026 后接真实数据。
3. **配置检查**：`GET /assistants/{id}/checks` 返回问题列表（严重级别：阻断 / 高影响 / 提示），至少包括：未选模型、模型不再启用、提示词为空、挂载资源失效（GLB-083、RUL-011）。发布（T-024）时调用。
4. 能力页签：挂载列表与“挂载能力”弹窗（AST-062），写入草稿；失效资源红色显示。

## 验收标准

- [ ] 编辑草稿不改变线上版本（T-024 后补集成测试）。
- [ ] 配置检查覆盖上述规则并有单元测试。
