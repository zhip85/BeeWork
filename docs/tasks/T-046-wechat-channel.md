# T-046 微信公众号渠道

**版本**：V0.3　**依赖**：T-041、T-043　**PRD**：3.7.1 微信、CHN-026、PLT-081
**外部条件**：已认证的微信公众号（服务号）App ID / App secret，或微信公众平台测试号；中国大陆区域部署要求见 NFR-007

## 范围

1. 适配器：App ID、App secret（加密）、Token 与 EncodingAESKey（平台生成，安全模式加解密）。
2. 回调 `/v1/channels/wechat/{instance_id}/callback`：签名校验、消息去重、5 秒内被动回复限制——**先回复空串并改用客服消息接口异步下发**；access_token 由 Worker 统一刷新并缓存（Valkey，按实例隔离）。
3. 渲染：文本、图片、图文（富媒体）；小程序卡片需要关联小程序，本任务只做配置项预留；表格/表单关闭；不流式。
4. 终端用户 = OpenID（加密存储）。
5. 中国大陆区域租户：只能绑定使用境内备案模型的助理（NFR-007，发布时检查助理模型区域）。

## 验收标准

- [ ] 签名与加解密单元测试（官方示例向量）；用测试号跑通一次真实收发（有账号时）。
