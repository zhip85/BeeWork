# T-141 AI 门户 · 门户设置

**版本**：V0.4　**依赖**：T-140　**PRD**：演进 PRD 10.4、9.3（个人记忆开关）、11.5、11.6；原型“AI 门户 → 门户设置”

## 数据

`portal_settings`（每租户一行，`row_version`）：
- 品牌与默认体验：门户名称（默认“{租户名} AI”）、输入框提示语、默认可见范围（新建应用的默认值）、默认回答风格（简洁 / 均衡 / 详细）。
- 导航与内容发现：搜索、项目、AI 应用库、最近使用、置顶对话（布尔）。
- 会话能力：文件上传、语音输入（布尔；真实上传与语音在 T-148，开关先存）。
- 员工个人设置：允许编辑个人资料与偏好、个人记忆、任务完成通知（布尔）。
- 下架应用历史会话：`readonly`（默认）/ `hidden`。

## 接口与权限

- `GET /portal/settings`（`portal:view`）、`PUT /portal/settings`（`portal:edit`，`row_version`，审计记录变更字段名与新旧值，不记录长文本全文）。
- `GET /portal/me/config`（员工端读取，需租户成员身份）：只返回员工端需要的开关与品牌，不含管理字段。

## 生效规则（服务端强制，不只靠前端隐藏）

关闭某项后，员工端对应**接口**也要拒绝（403 `portal.feature_disabled`）：关闭项目 → 项目接口拒绝且对话不能关联项目；关闭置顶 → 置顶接口拒绝；关闭个人资料编辑 → 资料修改接口拒绝；关闭个人记忆 → 停止为该租户门户对话写入个人记忆，员工端记忆入口消失（已有数据按 T-056 的保留与删除策略处理，在设置页说明）。员工端前端按 `/portal/me/config` 隐藏入口。

## 界面

管理端“门户设置”页签按原型四组开关 + “预览”“保存设置”；保存后提示成功，失败不误报成功（演进 PRD 16.2）。
