# T-131 中国大陆区域合规：境内模型与生成内容标识

**版本**：V1.0　**依赖**：T-041、T-014　**PRD**：NFR-007、PLT-020 第 4 步「中国大陆（上海）PIPL · 生成式 AI 标识」

## 范围

1. 模型限制：平台模型目录增加“境内备案”属性；中国大陆区域租户只能启用区域为中国上海且已备案的模型（现有区域可见规则基础上加备案校验）；降级模型同样受限。
2. 生成内容标识：中国大陆区域租户的渠道输出带显式标识（网站/H5 气泡角标“AI 生成”、开放 API 响应字段 `ai_generated: true`、IM 渠道文本前缀可配置），文案与位置做成平台配置项；隐式标识（元数据）写入消息记录。具体标识要求以部署时的法规要求为准，开工时由开发负责人与法务确认并记录。
3. 区域合规模板：开通时应用（PLT-021 第 4 步），与 T-050 的基线下发范围“中国区域租户”联动。

## 验收标准

- [ ] 测试：中国区域租户启用非备案模型被拒；各渠道输出带标识。
