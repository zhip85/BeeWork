# T-059 OC · 组件编排

**版本**：V0.3　**依赖**：T-054、T-041、T-043　**PRD**：3.6.8（OC-070–074）、CHN-021–023、3.7.6 末段（组件事件回传）

## 范围

1. 配置（OC-070–071）：总开关、每轮最多组件数（1–5，越界收敛）、JSON 校验失败策略（降级文本 / 重试一次 / 丢弃）、文本降级模板。
2. 注入预览（OC-072）：列出绑定本助理的渠道实例及其**已发布快照**中的组件；展开显示注入提示词全文。
3. 提示词生成（OC-073）：按模板生成中英两版，按助理默认语言选择；函数 `build_component_prompt(snapshot, oc_config, locale)` 与渠道发布弹窗（T-041 CHN-022）共用。
4. 运行时（OC-074）：只读渠道已发布快照；解析回复中的 `<标签>JSON</标签>`，按组件 schema 校验（简化 schema 与标准 JSON Schema 两种，校验器由 T-043 提供）；native / json（开放 API 响应 `widgets` 字段）/ text（降级模板）/ off；超过上限丢弃；失败按策略处理（重试仍失败降级文本）；处理结果写 trace。
5. 终端用户在组件上的操作（按钮、预约确认）以结构化事件回传，作为下一轮输入（渠道 SDK 与开放 API 增加 `event` 消息类型）。
6. 编排总览组件摘要。

## 验收标准

- [ ] 单元测试：解析多个标签、非法 JSON、schema 不符、超上限、各模式输出。
- [ ] 测试：修改组件库中组件不影响已发布渠道快照的注入内容（CHN-025）。
