# T-105 租户永久删除的数据清除、删除证明与租户数据导出

**版本**：V1.0　**依赖**：T-005、T-086、T-121　**PRD**：PLT-053、PLT-070–071（租户数据导出双人复核）、3.12.5 生命周期说明（只读可导出、停用仅主管理员导出）、NFR-010、NFR-013

## 范围

1. 清除任务 `tenant.purge`（T-005 把租户置为“已删除”后入队）：按清单删除该租户全部业务数据（数据库各租户表、对象存储前缀、RAGFlow datasets、LiteLLM team 与虚拟 Key、私有 deployment、Langfuse traces（按 T-084 实测结论）、Valkey 键）；每一类记录删除数量与时间，可重试、幂等；审计与操作记录**不删除**（保留元数据用于审计，NFR-011）。
2. 删除证明：生成包含租户编码、删除范围清单、各类数量、完成时间、备份将于 30 天内自然过期的说明，以及内容哈希（并写入平台审计链）的 PDF/JSON；平台可下载。
3. 新增“清单完整性测试”：遍历 ORM 中所有带 `tenant_id` 的表，断言都在清除清单中（防止以后新增的表漏删）。
4. 租户数据导出：
   - 租户侧：只读状态所有角色可导出，停用状态仅主管理员可导出（PLT-053），复用 T-086 的导出任务框架，导出全量业务数据 JSON 包。
   - 平台侧：“租户数据导出”属于高危操作，双人复核后执行（PLT-071），且平台人员只能拿到加密包与交付记录，不在后台浏览内容（PER-011）。

## 验收标准

- [ ] PostgreSQL 测试：清除后所有租户表中该租户 0 行；其他租户数据不受影响；重复执行幂等。
- [ ] 清单完整性测试通过。
