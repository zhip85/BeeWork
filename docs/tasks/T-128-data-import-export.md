# T-128 业务数据导入导出与环境迁移包

**版本**：V1.0　**依赖**：T-110、T-061、T-053　**PRD**：NFR-019、RUL-004

## 范围

1. 对象级 JSON 导出/导入：助理（草稿配置含 OC，或某个已发布版本快照）、智能体（Agent / Chatflow / Workflow）、知识库 FAQ（JSON 与 CSV）、术语（CSV，复用 T-051 解析器）、PII 规则。格式带 `format_version`，使用 T-110 的集合序列化。
2. 迁移包：选择多个对象打包，导入时做引用重映射（按名称匹配目标租户中的资源，无法匹配的列为待处理项）、名称冲突策略（跳过 / 重命名 / 覆盖草稿）、导入只生成草稿（不直接发布）。
3. 权限与审批：导出受“允许导出”与数据导出审批策略约束（T-086）；导入需要对应模块的编辑权限。
4. 不导出密钥、凭证、终端用户数据与会话。

## 验收标准

- [ ] 往返测试：导出 → 导入到另一个租户 → 再导出，内容一致（除 ID 与时间）。
- [ ] 测试：导出包中不含任何密文字段。
