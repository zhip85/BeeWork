# T-094 开放 API 扩展：知识与分析接口、OpenAPI 文档

**版本**：V1.0　**依赖**：T-028、T-031、T-032、T-085　**PRD**：SET-090 权限范围、NFR-017

## 范围

1. `knowledge.read`：列出知识库、文档与状态、FAQ；检索接口（与运行时同一检索服务，只能检索本租户的知识库）。
2. `knowledge.write`：上传文档（同 T-031 校验与配额）、删除文档、FAQ 增删改与发布（受“发布知识库更新”审批策略约束，审批开启时返回 202 + 审批单 ID）。
3. `analytics.read`：工作台指标与助理日统计（T-085 的数据）、会话列表（不含正文）。
4. OpenAPI 文档：`/v1` 开放接口单独生成文档与 JSON（与控制台 API 分开），版本化路径；兼容期 ≥ 12 个月的约定写进 architecture.md（破坏性变更必须走 `/v2`）。
5. 统一错误码 `{error: {code, message}}` 与限流 429 + `Retry-After`（与 T-028 一致）。

## 验收标准

- [ ] 测试：每个范围缺失时 403；跨租户 404；`knowledge.write` 在审批开启时不直接生效。
- [ ] CI 增加“开放 API OpenAPI 文档与上一版本对比”检查：删除字段或接口时失败。
