# T-082 会话标注

**版本**：V0.3　**依赖**：T-080、T-032、T-027　**PRD**：3.8.3（OPS-020–023）、6.1 运营 · 会话标注

## 范围

1. `conversation_annotations`：会话、消息、标签（正确 / 回答错误 / 不安全 / 缺少知识）、备注（≤ 500 字）、标注人、状态（待处理 / 已解决）。
2. 创建（OPS-021）：会话详情中对某条助理回复打标签；列表“新建”需先选择会话与消息。
3. 列表（OPS-020）：搜索、状态、标签、助理筛选。
4. 处理（OPS-022）：“缺少知识”一键生成 FAQ 草稿到指定知识库（问题取用户原话，调用 T-032 服务，运营角色可用）；“回答错误”“不安全”可加入测试用例（T-027）；标记已解决。
5. 统计（OPS-023）：标注结果计入助理概览质量指标与工作台待办（T-085 读取）。

## 验收标准

- [ ] 测试：权限按 6.1（管理员 V E D、构建者与运营 V E、其余 V）；生成的 FAQ 为草稿且不被检索；跨租户 404。
