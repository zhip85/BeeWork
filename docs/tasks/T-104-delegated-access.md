# T-104 代管登录

**版本**：V1.0　**依赖**：T-023、T-100　**PRD**：PLT-041、PER-005、PER-011、PLT-070–071、6.2

## 范围

1. 申请：平台管理员在租户详情发起，选择模式（只读 / 代操作）与原因；生成待处理操作记录；**代操作模式先经平台双人复核（PLT-071）**，通过后才向租户发请求。
2. 授权：租户主管理员在通知中同意或拒绝，选择时长 1 / 4 / 24 小时；租户可随时撤销。
3. 代管会话：平台管理员以“代管身份”进入租户控制台（独立会话令牌，带 `impersonation_id`），顶部显示代管提示条与剩余时间；到期或撤销立即失效。
4. 限制（PER-005）：权限不超过所选模式；代操作也不能修改成员、SSO、BYOK、API 密钥（服务端在这些接口统一拒绝代管会话）；只读模式下所有写接口 403。
5. 审计：代管期间每个请求写入租户审计（标注“平台代管 · 操作人”）与平台审计。

## 验收标准

- [ ] 测试：未授权不能进入；只读模式写操作 403；代操作修改成员 403；过期/撤销后令牌失效；审计双写。
