# T-062 Chatflow / Workflow 流程画布与编译器

**版本**：V0.2　**依赖**：T-060、T-061　**PRD**：3.3.5（AGT-040–045）、5.4 RUL-014、technical-plan 第 5 节

## 节点 DSL（`runtime/flow_dsl.py`）

11 种节点（AGT-040）：agent、classify、extract、copilot、human_review、connector、function、variable、if_else、loop、comment。每个节点：`id`、`type`、`name`、`instruction`、类型专属字段（引用对象 ID、分支目标、循环起点、最大次数 1–100 等）。节点按列表顺序自上而下执行，开始/结束为隐式节点。

## 表达式（开发负责人决定，可逆）

不开放任意代码（technical-plan 第 5 节、NFR-009）。**函数、变量节点与条件**使用 JMESPath 表达式（以 `=` 开头），在受限求值器中执行（输入大小、结果大小、耗时上限）；If/Else、分类、循环条件若不是表达式，则作为自然语言条件交给模型做是/否（或类别）判定。函数节点的“沙箱代码执行”不在本期，界面上说明。

## 编译器

- `compile_flow(config) -> CompiledGraph`：顺序边；If/Else 指向“结束”或后续节点；循环回到前序节点并计数，超过最大次数后继续向下；人工审核节点交给 T-065 的中断实现（本任务先实现为“未支持”错误）。
- 分类、提取：LiteLLM 结构化输出；智能体 / Copilot：调用可用的 Agent 或 Workflow（深度规则同 T-061）；连接器：经 T-071 执行器调用工具。
- 节点完整性（AGT-045）注册到 T-060 的配置检查器。
- 运行时每个节点一个 span，节点结果（耗时、跳过、输出摘要）写 run 事件，供调试预览与试运行轨迹展示。

## 画布（AGT-041–042）

- 按 PRD 的纵向顺序画布实现（开始 → 节点卡 → 结束），不做自由连线图；节点库、选中高亮、序号、状态文字、分支摘要、上移/下移、删除后选中第一个节点并把指向被删节点的分支/循环置为未配置。
- 右侧节点设置面板字段随类型变化（AGT-042）。

## 验收标准

- [ ] 编译器单元测试（假模型）：分支跳转、循环次数上限、注释节点不执行、引用自身被拒、表达式求值限制（超大输入、超时）。
- [ ] 画布保存/恢复后配置一致（前端单元测试或 Playwright）。
