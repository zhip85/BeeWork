# T-042 渠道体验四级继承与体验编辑器

**版本**：V0.3　**依赖**：T-041　**PRD**：3.7.5（CHN-030–035）、3.7.1 体验继承、PLT-101、5.3 渠道体验、8.3#9

## 范围

1. 存储：平台层在 `channel_types.default_experience`；租户层 `tenant_channel_styles`（每类型一份）；助手层 `draft_config.channel_experience[类型]`（随助理版本发布）；实例层 `channel_instances.experience_overrides`。每层只存与上级不同的字段。
2. 合并函数 `effective_experience(type, tenant, assistant, instance) -> (values, sources)`，返回每个字段的来源层，供编辑器显示来源徽标与“恢复继承”。
3. 体验编辑器（CHN-030–034）：四种层级模式、继承链高亮、层级特有字段、配置项表（开放 API 只显示适用项）、实时预览（设备框 / JSON 示例）。
4. 入口（8.3#9 按 PRD 补充）：平台“渠道类型 → 编辑平台默认”；租户“渠道 → 渠道类型 → 编辑租户默认”；助手“助理详情 → 渠道页签”；实例“渠道列表 → 体验”。
5. 平台默认修改只影响未覆盖该字段的下级，已发布快照不变（PLT-101）。
6. 欢迎语 ≤ 200 字；主题、圆角、入口形式按类型限制可选值。

## 验收标准

- [ ] 合并函数表驱动单元测试（四层覆盖组合、恢复继承、类型切换清空覆盖）。
- [ ] 测试：修改租户默认后，未重新发布的渠道线上体验不变。
