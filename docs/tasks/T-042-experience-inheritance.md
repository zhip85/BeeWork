# T-042 渠道体验四级继承与体验编辑器

**版本**：V0.3　**依赖**：T-041　**PRD**：3.7.5（CHN-030–035）、3.7.1 体验继承、PLT-101、5.3 渠道体验、8.3#9

## 范围

1. 存储：平台层在 `channel_types.default_experience`；租户层 `tenant_channel_styles`（每类型一份）；助手层 `draft_config.channel_experience[类型]`（随助理版本发布）；实例层 `channel_instances.experience_overrides`。每层只存与上级不同的字段。
2. 合并函数 `effective_experience(type, tenant, assistant, instance) -> (values, sources)`，返回每个字段的来源层，供编辑器显示来源徽标与“恢复继承”。
3. 体验编辑器（CHN-030–034）：四种层级模式、继承链高亮、层级特有字段、配置项表（开放 API 只显示适用项）、实时预览（设备框 / JSON 示例）。
4. 入口（8.3#9 按 PRD 补充）：平台“渠道类型 → 编辑平台默认”；租户“渠道 → 渠道类型 → 编辑租户默认”；助手“助理详情 → 渠道页签”；实例“渠道列表 → 体验”。
5. 平台默认修改只影响未覆盖该字段的下级，已发布快照不变（PLT-101）。
6. 欢迎语 ≤ 200 字；主题、圆角、入口形式按类型限制可选值。

- [ ] 测试：修改租户默认后，未重新发布的渠道线上体验不变。

**后端**
- `experience.py`：体验项表（品牌主色、主题、圆角 0/8/12/16、入口形式、欢迎语 ≤ 200 字、快捷回复 / 卡片 / 表格 / 表单、流式；开放 API 没有主色、主题、圆角、入口、欢迎语；入口按类型限制：网站 右下 / 左下，H5 全屏 / 底部抽屉，WhatsApp、微信、开放 API 各一种）；`validate_layer()` 按类型校验一层的值（空值 = 继承，不适用的项 / 非法值 422）；`resolve()` 合并四层并给出每项的来源层。
- 四层：平台 = `channel_types.default_experience`（目录默认值补全为 PRD 3.7.1 的完整集合）；租户 = `tenant_channel_styles`；智能体 = `draft_config.channel_experience[类型]`（随智能体草稿与版本走；**智能体的问候语是它的欢迎语，除非它的渠道配置另设**）；渠道 = `channel_instances.experience`（可另存显示名称）。下层只存与上层不同的字段。
- 接口：`GET /experience/{类型}?assistant_id=&channel_id=`（编辑器所需：字段表、各层自己的值、合并结果与来源、问候语、版本）；`PUT /channel-types/{类型}/tenant-experience`；`PUT /assistants/{id}/channel-experience/{类型}`（乐观锁）；`PUT /channels/{id}/experience`（乐观锁）；平台继续用 `PATCH /platform/channel-types/{code}` 的 `default_experience`（现在会校验）。权限 `channels:view / edit`，智能体层另需能编辑该智能体；跨租户 404；审计。
- 发布：快照里冻结**每一个适用项的合并结果**（原先只有主色 / 名称 / 欢迎语）；渠道响应带 `effective_experience` 与 `experience_sources`；上层（平台、租户、智能体）改动会让草稿将冻结的值与线上不同，列表显示“有未发布修改”，**已发布渠道线上不变**，重新发布后才生效（8.3#9）。
- 兼容：`update_assistant` 在客户端没发 `channel_experience` 时保留已存的值，不会因为别处编辑智能体而清掉渠道配置；渠道响应里的 `experience` 现在只含渠道自己设置了的项（T-040 的一条旧断言随之更新）。

**没做或要注意**
1. **网站挂件目前只用主色、显示名称和欢迎语**：主题、圆角、入口形式、快捷回复 / 卡片 / 表格 / 表单开关、流式开关已经写进发布快照，但 `widget.js`、H5、IM 渠道的运行时还没有消费它们（挂件的圆角 / 深色 / 左下角、按开关降级表格等要和 H5 一起做，T-044）。
2. WhatsApp 平台默认圆角 PRD 写的是 10，但圆角只允许 0 / 8 / 12 / 16，我用了 8。
3. 智能体层读的是智能体的**草稿配置**（和 T-040 读问候语的方式一致），不是线上版本的快照；“随智能体版本发布”只体现在它存进了草稿和版本快照。
4. “租户模板”下拉（CHN-032：助手层可选择租户样式模板）没有做；租户层目前每类型只有一份默认值。
5. 页面没有目视验收。
