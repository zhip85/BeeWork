# T-106 平台运营后台角色分权

**版本**：V1.0　**依赖**：T-100　**PRD**：PER-010、6.2、8.3#10

## 问题（阻塞，需要产品决策）

PRD 只有一种平台角色，建议拆分为平台超级管理员、租户运营（客户成功）、平台配置管理员、平台审计员，但未给出权限矩阵（8.3#10 待确认）。开工前需要确认：

1. 是否按上述四种角色拆分；
2. 每种角色对 6.2 各功能的 V / E / D 与复核权限；
3. 双人复核是否要求两人具备特定角色（如：停用租户需超级管理员复核）；
4. 现有平台管理员账号迁移为哪种角色。

## 决策后的实现范围（预案）

- 平台权限点目录（与租户 `PERMISSION_CATALOG` 分开）、平台角色表、`require_platform_permission("tenants:edit")` 依赖替换 T-001 的 `require_platform_admin`；平台菜单按权限显示；平台审计带角色。
