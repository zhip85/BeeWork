# T-065 人工审核节点

**版本**：V0.2　**依赖**：T-062、T-022、T-023　**PRD**：AGT-040 人工审核、3.3.5 运行时说明、3.9

## 范围

1. 节点配置：审核条件（表达式或自然语言，T-062 规则）、审批人。**开发负责人决定（PRD 未写审批人）**：可选“租户管理员 / 助理负责人 / 指定角色”，默认租户管理员。
2. 运行时：条件满足时创建审批单（审批类型“流程审核”，标题「{流程名} · {节点名}」，`change_diff` 放运行输入与上游节点输出摘要，已脱敏），run 状态 `waiting_approval` 并通过 LangGraph `interrupt` 暂停；审批通过 → 执行器 `@approval_action("flow.review")` 入队恢复运行；驳回 → 运行失败并返回“人工审核未通过”；审批过期（7 天）→ 运行失败。
3. 该审批不受审批策略开关影响（节点本身就是审批要求），在审批中心正常展示与处理，申请人显示为“流程 {名称}”。
4. Chatflow 中等待审批时，终端用户收到“正在等待人工审核”提示。

## 验收标准

- [ ] 测试：通过后从下一节点继续；驳回终止；审批单与 run 双向可追溯；重复通过不重复恢复（幂等）。
