# T-040 网站渠道（最小版）

**阶段**：6（试点版范围内的最小子集）　**依赖**：T-024、T-025　**PRD**：3.7.2–3.7.4（网站类型部分）、RUL-003、5.5 第 1 步、4.9

## 范围

1. `channel_instances`：类型先只支持 `website`；名称、绑定助理、环境、允许嵌入的域名白名单、外观（主题色、助手名称、欢迎语，默认继承助理与企业信息）、状态（草稿/启用/停用）、`published_snapshot`（发布时冻结）、`site_key`（公开标识，非密钥）。
2. 发布：生成快照（体验配置 + 绑定助理版本策略），首次发布受“接入新的外部渠道”审批策略约束（T-022）。线上只读快照（RUL-003）。
3. 公开接口（`/v1/widget/*`）：用 `site_key` + `Origin` 白名单认证，签发短期的终端用户会话令牌；对话复用 T-028 的对话执行路径（生产环境用线上版本）。限流与 QPS 配额同 T-028。
4. 嵌入脚本：`frontend` 外单独构建一个轻量 `widget.js`（无 React 依赖或最小依赖），由 API 静态提供；提供一段复制即用的嵌入代码。
5. 渠道列表页与创建向导的最小版本（只有网站类型），以及助理详情“渠道”页签。

## 验收标准

- [ ] 非白名单 Origin 被拒绝；`site_key` 不能调用其他租户的助理。
- [ ] 修改未发布配置不影响线上（RUL-003 测试）。
- [ ] 本地 HTML 页面嵌入脚本跑通一次真实对话。
