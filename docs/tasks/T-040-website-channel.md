# T-040 网站渠道（最小版）

**阶段**：6（试点版范围内的最小子集）　**依赖**：T-024、T-025　**PRD**：3.7.2–3.7.4（网站类型部分）、RUL-003、5.5 第 1 步、4.9

## 范围

1. `channel_instances`：类型先只支持 `website`；名称、绑定助理、环境、允许嵌入的域名白名单、外观（主题色、助手名称、欢迎语，默认继承助理与企业信息）、状态（草稿/启用/停用）、`published_snapshot`（发布时冻结）、`site_key`（公开标识，非密钥）。
2. 发布：生成快照（体验配置 + 绑定助理版本策略），首次发布受“接入新的外部渠道”审批策略约束（T-022）。线上只读快照（RUL-003）。
3. 公开接口（`/v1/widget/*`）：用 `site_key` + `Origin` 白名单认证，签发短期的终端用户会话令牌；对话复用 T-028 的对话执行路径（生产环境用线上版本）。限流与 QPS 配额同 T-028。
4. 嵌入脚本：`frontend` 外单独构建一个轻量 `widget.js`（无 React 依赖或最小依赖），由 API 静态提供；提供一段复制即用的嵌入代码。
5. 渠道列表页与创建向导的最小版本（只有网站类型），以及助理详情“渠道”页签。

## 验收标准

- [ ] 非白名单 Origin 被拒绝；`site_key` 不能调用其他租户的助理。
- [ ] 修改未发布配置不影响线上（RUL-003 测试）。
- [ ] 本地 HTML 页面嵌入脚本跑通一次真实对话。

**行为**
- 渠道实例（仅 `website`）：名称（租户内不区分大小写唯一）、绑定助理、环境（受套餐限制）、允许嵌入的域名白名单（规范化为 `scheme://host[:port]`；只允许 https，仅 localhost 可用 http；最多 20 个；不接受路径/账号）、体验覆盖（主色、助手名称、欢迎语；留空则继承助理的名称与开场白，再到平台默认）、状态（草稿/启用/停用）、公开的 `bw_site_` 站点标识。
- 发布（RUL-003）：冻结快照（名称、助理、环境、域名白名单、生效的体验）。走“接入新的外部渠道”审批策略：关闭则立即生效（200），开启返回 202 与审批单，通过后由 Worker 执行；生产环境渠道需要助理已发布，开发/预发使用最新草稿；需至少一个域名。**编辑只改草稿**（列表显示“有未发布修改”），访客看到的白名单与体验都来自快照；重新发布才生效，从白名单移除的域名随之失效。同一渠道同时只能有一个待审批单。
- 公开接口（`/v1/widget/*`）：`POST /session`（`site_key` + `Origin` 必须在已发布快照的白名单内，签发 1 小时的访客令牌，令牌绑定渠道、访客与来源，用从服务端密钥派生的独立密钥签名）、`POST /chat`（Bearer 访客令牌 + 同一 `Origin`；对话走与开放 API 相同的路径：生产跑线上版本；SSE；QPS 与按来访地址的限流）、`GET /conversations/{id}/messages`（只能读本访客在本渠道的会话）。`site_key` 单独不能调用任何助理：访问哪个助理由渠道快照决定，请求里没有可选参数。仅在来源通过校验后才返回 CORS 头；预检请求不泄露任何信息。停用渠道、停用助理、删除渠道或重置 `site_key` 立即生效。
- 嵌入脚本 `widget.js`：单文件、无依赖，由 API 以静态文件提供（`/v1/widget.js`，可缓存 5 分钟）；Shadow DOM 隔离样式；浮动按钮与对话面板；流式显示；记住访客与会话；令牌过期自动换新；回复只以文本渲染（不使用 `innerHTML`）。接入代码为 `<script src="…/v1/widget.js" data-site-key="…" async></script>`（地址取 `PUBLIC_API_URL` 或请求地址）。

**遗留问题**
- “本地 HTML 页面嵌入脚本跑通一次真实对话”：已用 jsdom 跑通，**需要你在真实浏览器里打开一个 HTML 页面再确认一次**（接入代码在渠道的“获取接入代码”里；开发时可把页面放在 `http://localhost:<端口>` 并把它加入允许域名）。
- 体验只有三项（主色、助手名称、欢迎语），没有四级继承与体验编辑器（T-042）；挂件只显示纯文本（无 Markdown/卡片/表单，属 T-043）；没有组件、H5 等其他渠道类型、没有向导的第 2 步（T-041/T-044）。
- 渠道的体验修改需要重新发布才生效（PRD 的待确认项，这里按“须重新发布”实现）。
- 用量列（近 30 天会话数）未做；渠道的会话可在会话记录里看到来源为 `website`。
- 开发租户只有一位管理员，“接入新的外部渠道”审批默认开启（审批人角色默认安全负责人，没人时回退到租户管理员），管理员自己发布会被拒绝；需第二位管理员或在审批策略里关闭。
