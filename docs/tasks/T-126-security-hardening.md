# T-126 安全加固与供应链门禁

**版本**：V1.0（生产门禁）　**依赖**：无（可分批提前）　**PRD**：NFR-008、NFR-009、technical-plan 第 3 节许可门禁、第 8 节安全测试

## 范围

1. Web 安全：CSP（禁止内联脚本，网站 SDK 单独策略）、安全响应头、Cookie 属性复核、CORS 白名单、上传与下载的 Content-Disposition。
2. 供应链：CI 增加 `pip-audit`、`npm audit`（或 osv-scanner）、镜像扫描（Trivy）、SBOM 生成、密钥扫描（gitleaks）；高危漏洞阻断合并。
3. 许可门禁：生成第三方依赖许可清单，标出 AGPL/SSPL/非商用条款组件，交开发负责人与法务确认（technical-plan“版本和开源许可门禁”）。
4. 安全测试套件：跨租户 IDOR 自动化回归（遍历所有带资源 ID 的接口）、SSRF 用例集、提示注入与工具越权用例（与 T-071、T-055 配合）、文件上传边界、密钥泄露哨兵测试。
5. 威胁模型文档与外部渗透测试准备清单 `docs/security/`。

## 验收标准

- [ ] CI 中各扫描步骤运行并在发现高危时失败；IDOR 遍历测试覆盖所有租户资源接口（新增接口未覆盖时测试失败）。
