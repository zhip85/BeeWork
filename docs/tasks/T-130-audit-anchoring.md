# T-130 审计防篡改外部存证与保留期

**版本**：V1.0（生产门禁）　**依赖**：T-121、T-002　**PRD**：NFR-011、PLT-072、SET-110、development-status 阶段 1 缺口“外部存证、生产清理调度/告警”

## 范围

1. 外部存证：Worker 每日把审计哈希链的当日链头（租户链与平台链）写入 WORM 存储（S3 Object Lock 合规模式，或部署方提供的等价能力），记录存证位置；校验接口对比库内链头与存证。
2. 保留期：租户审计 365 天（已有）；平台操作审计 ≥ 3 年（PLT-072、NFR-011），把平台审计排除出 365 天清理并改为 3 年；清理任务失败或链校验失败时告警（T-123 / T-088 安全事件）。
3. 已删除租户的审计按保留期继续保存（与 T-105 一致）。

## 验收标准

- [ ] 测试：篡改库内审计记录后校验报警；平台审计 366 天的记录不被清理。
