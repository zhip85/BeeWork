# T-093 登录安全策略、MFA 与个人资料

**版本**：V1.0　**依赖**：T-004　**PRD**：SET-032、GLB-009（个人资料、界面语言）、PER-005（代管不能修改 SSO/MFA 等）

## 范围

1. 租户登录安全设置（SET-032）：强制 SSO（开启后该域名成员只能 SSO，租户管理员保留密码登录应急通道）、MFA（关闭 / 管理员必须 / 全员必须）、密码策略（最小长度、复杂度、有效期）、会话超时（15 分钟–7 天，接入 T-004 的后端参数）、IP 白名单（CIDR 列表，保存前校验当前操作者 IP 在内，防止把自己锁在外面）、登录失败锁定参数展示（T-004 已实现）。
2. MFA：TOTP（RFC 6238）绑定、恢复码（只存哈希）、登录二次校验；平台管理员账号同样支持并建议强制。
3. 个人资料（GLB-009）：姓名、头像字母、修改密码（校验旧密码、符合策略、其他会话下线）、界面语言（T-003 已有偏好接口）、MFA 绑定与解绑。
4. 全部写审计（安全分类）；锁定、MFA 失败、IP 拒绝触发“安全事件”（T-088）。

## 验收标准

- [ ] 测试：开启“管理员必须 MFA”后未绑定的管理员登录被引导绑定；IP 白名单外请求 403；密码过期强制修改；时间窗内 TOTP 重放被拒。
