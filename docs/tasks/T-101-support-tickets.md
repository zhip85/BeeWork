# T-101 运维与工单

**版本**：V1.0　**依赖**：T-008、T-087　**PRD**：3.13.1（PLT-060–064）、SET-080 申请升级、PLT-032 申请迁移、8.3#13

## 范围

1. `support_tickets`：工单号 `TCK-序号`（全局序列）、标题、租户、级别 P1–P4、类型（咨询 / 故障 / 变更申请 / 迁移）、负责人（平台成员）、描述、附件（经 T-121 存储与扫描，T-121 前为本地卷）、状态（待处理 / 处理中 / 已解决 / 已关闭）；不可删除只能关闭（PLT-064）。
2. 时间线 `ticket_events`：评论（对租户可见 / 内部备注）、状态变更、负责人变更。对租户可见的回复同步到租户端。
3. 来源（PLT-060）：租户管理员在租户控制台提交（新增“帮助 → 我的工单”页与“申请升级”入口）；系统自动创建（迁移申请、配额达 100%、渠道/MCP 持续异常、开通失败）——提供 `create_system_ticket()`，相关任务调用；平台手工创建。
4. SLA（PLT-063，8.3#13 暂按 PRD）：首次响应 P1 15 分钟、P2 1 小时、P3 4 小时、P4 1 个工作日（工作日历先按周一至周五、租户时区 9–18 点）；超时标红并通知负责人及客户成功负责人。
5. 平台后台“运维与工单”页与详情；平台写操作写平台审计。

## 验收标准

- [ ] 测试：租户只能看到自己租户的工单与“对租户可见”的回复；内部备注对租户不可见；SLA 计时（可注入时钟，含跨周末）。
