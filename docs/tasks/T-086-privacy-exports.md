# T-086 数据导出审批、终端用户数据导出/删除与训练开关

**版本**：V0.3　**依赖**：T-022、T-056、T-080、T-084　**PRD**：NFR-010、PER-002、SET-070（数据训练、允许导出、数据区域）、OPS-004 导出、AST-072、SET-110 审计导出、3.9.1 数据导出

## 范围

1. 导出任务框架：`export_jobs`（范围、格式 CSV/JSON、状态、文件位置、过期时间、申请人）；Worker 生成文件到租户隔离存储，下载链接短期有效（签名 URL，24 小时），下载写审计。
2. 数据导出审批（PER-002）：会话导出、审计导出、终端用户数据导出先检查“允许成员导出会话记录”开关（关闭时入口隐藏且接口 403），再走“数据导出”审批策略（默认关）；通过后执行器入队生成文件。
3. 终端用户数据权利（NFR-010）：按终端用户（租户内 ID）导出全部数据（会话、消息、记忆、反馈、工单）与删除全部数据（同上 + run 输入输出置空 + Langfuse trace 删除（按 T-084 实测结论）+ 工具调用记录关联断开）；删除不可撤销、需二次确认、写审计（只记录终端用户 ID 哈希）。提供控制台入口（会话详情用户信息处）与开放 API（`DELETE /v1/end-users/{id}`，新增权限范围 `privacy.manage`，开发负责人决定）。
4. “允许模型供应商使用数据训练”（SET-070）：平台模型目录增加 `zero_data_retention` 属性；开关关闭（默认）时，租户环境只能启用零保留模型，已启用的非零保留模型在配置检查中报阻断；开启需二次确认并写审计。
5. 数据存储区域只读展示（SET-070）。

## 验收标准

- [ ] 测试：开关关闭时导出 403；审批开启时未通过不产出文件；下载链接过期失效；跨租户不可下载。
- [ ] 测试：删除终端用户后，其会话、记忆、反馈不可再查询，运营统计数字保留（只删明细不改汇总）。
