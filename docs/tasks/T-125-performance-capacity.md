# T-125 性能与容量验证

**版本**：V1.0（生产门禁）　**依赖**：T-124　**PRD**：NFR-001、NFR-002、NFR-003、NFR-005、technical-plan 第 7 节 SLO

## 范围

1. 压测脚本（k6 或 Locust，开工时选定）：控制台列表接口、开放对话 API（流式）、网站渠道、知识检索、Worker 吞吐。
2. 用 LiteLLM `mock_response` deployment 隔离模型耗时，测 OC 管线自身耗时（NFR-001 P95 ≤ 300 ms）；真实模型首字响应单独测（有 Key 时）。
3. 容量目标：单租户 1000 并发会话（企业版）、平台 1000 租户数据量下的列表 P95 ≤ 500 ms、QPS/RPM 双重限流行为正确（NFR-005）。
4. 知识处理：10 MB 文档 ≤ 5 分钟、检索 P95 ≤ 300 ms（依赖 RAGFlow Cloud 套餐，结果如实记录）。
5. 报告 `docs/ops/performance.md`：环境、数据量、结果、瓶颈与优化项；未达标项不得标记为达成。
