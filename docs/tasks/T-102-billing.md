# T-102 配额调整、加购与月度账单

**版本**：V1.0　**依赖**：T-010、T-011　**PRD**：PLT-014、PLT-045（覆盖与加购）、PLT-046、PLT-084、RUL-020、RUL-023、3.12.6 登记回款

## 产品决策（开发负责人，可逆）

- 不接入在线支付：账单由系统按月生成，回款由平台人工“登记回款”。币种 USD；企业版“定制合同”价格在订阅中手工填写。
- 点数单价（用于软超额计费与 T-103 的“点数收入”）：**待产品确认**。在确认前以“套餐月价 ÷ 套餐月点数”作为每租户的隐含单价，并在页面标注“暂定口径”。

## 范围

1. 配额调整（PLT-046）：平台可修改单个租户某配额的上限、告警阈值、超额策略（硬限制 / 软限制 / 降级），写操作记录与平台审计。
2. 超额策略执行（PLT-084）：告警阈值通知租户与平台；硬限制拒绝；软限制允许并记录超额量；降级切换到降级模型（T-014）继续服务。
3. 加购与特批（PLT-045）：额外 100 万点数（叠加当月点数上限，RUL-020）、自定义域名、自带模型密钥（解锁 T-012）、Beta：动态组队；勾选即生效并写操作记录。
4. 账单（RUL-023）：Worker 每月 1 日为上月生成账单（套餐费 + 加购 + 软超额），状态待支付；到期未付置逾期；“登记回款”“作废重开”；账单 PDF 下载（服务端生成）。试用租户 $0。
5. 页面：平台“租户 → 用量与账单”（PLT-014 指标卡与表格）、租户详情“用量与账单”页签（配额表 + 账单表）；租户侧“订阅与用量”展示最近账单。
6. 与生命周期联动：登记回款可将宽限/只读租户恢复为正式（调用现有生命周期服务）。

## 验收标准

- [ ] 账单生成幂等（同一账期只生成一次）；金额计算单元测试（含软超额、加购、作废重开）。
- [ ] 测试：硬限制达到 100% 拒绝新增；降级策略下请求使用降级模型。
