# T-111 助理模板与行业包

**版本**：V1.0　**依赖**：T-110、T-020、T-051、T-053　**PRD**：AST-020（模板开始、模板市场弹窗）、AST-008、PLT-021–022（安装行业包）、PLT-033、4.13 模板市场

## 范围

1. 模板数据：`assistant_templates`（名称、行业（T-051 字典）、发布者、安装量、状态 Listed / Reviewing / Deprecated、模板内容 = 助理草稿配置片段：提示词、推荐模型类型、推荐挂载能力类型、会话体验、OC 默认值）。平台通过案例数据工作室的“模板市场”集合维护（T-110），本任务把该集合从通用 JSON 升级为正式表并做内容校验。
2. 行业包：一个行业包 = 一组模板 + 行业术语继承 + 示例 FAQ（可选）。预置：保险（销售、客服、理赔、合规、培训助理）、跨境电商（售前导购、售后、物流查询、多语种客服）、通用办公（人事、IT 服务台与制度问答助理）。内容由开发负责人提供初稿，产品确认后入库。
3. 安装：开通（T-100 第 5 步）或编辑租户切换行业包（PLT-033）时安装——为租户创建助理**草稿**（名称冲突时加后缀）、设置术语行业继承；已有内容保留；安装幂等。
4. 创建助理向导（AST-020）：“从空白开始 / 客户支持 / 销售副驾”卡片来自 Listed 模板；“浏览模板市场”弹窗（行业筛选、安装量、发布者），选中后预填后续步骤；安装量 +1。
5. 模板中的模型只写“类型偏好”，实际模型取租户当前环境默认模型；推荐挂载只作为提示，不自动挂载不存在的资源。

## 验收标准

- [ ] 测试：重复安装行业包不重复创建；切换行业包不删除已有助理；Deprecated 模板不可选。
