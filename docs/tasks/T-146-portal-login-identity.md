# T-146 AI 门户 · 登录与身份

**版本**：V1.0　**依赖**：T-142、T-091、T-092、T-095　**PRD**：演进 PRD 12（全部）、18.7；原型“AI 门户 → 登录与身份”

## 范围

1. 管理端“登录与身份”页签：“仅允许已认证员工访问”开关；从租户已配置并启用的身份提供方（T-091 OIDC / SAML、T-092 LDAP、T-095 企业微信）中勾选门户可用的登录方式；不在本页重复录入协议参数，只链接到设置里的身份提供方配置。页面注明“凭据仅保存在服务端”。
2. 员工登录页按勾选结果显示入口；协议校验、Token 交换全部在服务端（12.4）；登录成功进入 `/portal`，退出清除服务端会话。
3. 身份绑定租户、组织、部门与角色；首次登录自动创建为 `employee` 角色成员的规则沿用 T-091 SET-010（已验证域名 + 开关）。
4. 不同失败给不同反馈：认证失败、账号停用、会话过期、无门户权限（12.4）。
5. 登录方式变更与门户登录事件写审计。

## 验收标准

- [ ] 测试：未勾选任何方式时登录页显示“管理员尚未配置认证方式”且登录接口拒绝；勾选的方式与登录页一致；未启用的身份提供方不能被勾选。
- [ ] 用 T-091 的测试 IdP 跑通一次员工门户 SSO 登录，记录在 development-status。
