# T-013 模型配置跨环境发布

**版本**：V0.2　**依赖**：T-006、T-022　**PRD**：SET-040、SET-042、SET-045、RUL-004

## 范围

1. 每个租户环境增加配置版本号与更新时间（SET-040 显示「{配置版本} · 更新于 {日期}」）；每次保存递增。
2. “发布到预发 / 发布到生产”（SET-042）：把当前环境的启用模型、默认模型、密钥方式复制到目标环境，目标版本号递增，写审计，随后触发网关同步（T-005 入队）。非企业版没有该按钮。
3. 发布到生产走审批：**开发负责人决定（可逆）**——在审批策略中新增事件 `model_config_publish`「模型配置发布到生产」，默认开、租户管理员、1 级（迁移为现有租户补默认行，SET-071 页面多一行）。预发不需要审批。
4. 关闭模型时的影响提示（SET-045 补充）：若该模型被助理草稿/线上版本、智能体、OC 改写或路由模型显式引用，返回受影响对象列表，需确认后才关闭；默认模型仍按现有规则禁止关闭。引用查询使用 T-070 的引用服务，T-070 未完成时只检查助理。

## 验收标准

- [ ] 测试：复制内容正确且不含另一个环境的虚拟 Key；审批开启时通过前不生效；非企业版 403。
- [ ] 目标环境网关同步完成后，`check_gateway_e2e.py` 中预发 Key 能访问新启用的模型。
