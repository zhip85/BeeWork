# T-090 企业信息与组织架构补全

**版本**：V1.0　**依赖**：T-051、T-121　**PRD**：3.10.1（含 SET-001）、GLB-086（租户时区）

## 范围

1. 基本信息：Logo 上传（SVG/PNG ≤ 2 MB；SVG 服务端清洗去脚本，或转 PNG 存储，开发负责人倾向“转 PNG”）、企业名称（≤ 100）、租户 ID 只读、所属行业（T-051 字典）。
2. 品牌：助手展示名称、主题色（作为租户级渠道样式主色默认值，T-042）；白标套餐的控制台自定义域名与邮件模板预留字段（实现属于 T-124 / T-008 后续）。
3. 语言与区域：默认语言、时区（5 个选项）、已启用语言（默认语言不可取消）；租户时区供 GLB-086 与工作台问候语使用。
4. 组织架构（SET-001 正式版规则）：重命名、拖动调整上级（防成环）、同一上级下名称唯一、有子部门或成员时不可删除（现有规则核对）。
5. 表单类配置统一“保存更改”、离开未保存确认（3.10 总述）；全部写审计。

## 验收标准

- [ ] 测试：恶意 SVG 不会以原样返回给浏览器；拖动成环被拒；时区影响详情时间显示（前端测试）。
