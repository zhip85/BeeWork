# T-144 员工端 AI 应用库与表单模式

**版本**：V0.4　**依赖**：T-143；表单模式另依赖 T-064（Workflow 输入 Schema）与 T-075　**PRD**：演进 PRD 5.4、11.4、15.1、15.3

## 范围

1. **可见应用（服务端判定）**：`状态 = 已上架` 且 `员工属于可见范围`（全公司；指定组织含子组织；仅管理员 = 租户管理员角色）且 `来源仍可用`。抽成服务函数 `visible_apps(db, membership)`，T-140 的下架测试、T-143 的发消息校验共用。
2. 应用库页：按名称、描述、分类搜索与筛选；推荐应用置顶；空态“管理员尚未上架应用”（演进 PRD 16.2）。
3. 进入应用：`chat` 模式进入对话（T-143）；`form` 模式按 Workflow 输入字段生成表单，提交后运行并展示结构化输出与失败状态。
4. 首页“企业 AI”选择器与应用库使用同一可见列表。
5. 最小权限（15.3）：门户应用不能扩大来源的权限；调用时同时校验员工身份与应用可见性。

## 验收标准

- [ ] 测试：可见范围三种类型（含子组织继承）、下架、来源停用后不可见；伪造应用 ID 发起调用 404；表单模式必填缺失 422。

## 需求变更（2026-11-11）

- 可见应用条件加上“持有门户席位（或租户为全员不限）”（演进 PRD 5.4 v1.1）：`visible_apps` 对无席位成员返回空，由 T-151 实现，本任务的测试需覆盖这一条。
