# T-004 登录失败锁定与会话超时

**阶段**：1　**依赖**：T-001　**PRD**：SET-032（部分）、5.8 异常事件

## 范围

1. 连续 5 次密码错误锁定该账号 15 分钟（按账号计数，存 Valkey 或 PostgreSQL，需在多实例下正确）；锁定期间即使密码正确也拒绝，返回 `code="auth.locked"`、剩余时间；锁定与解锁写审计（安全类）。
2. 同一 IP 的高频失败限流（如 1 分钟 20 次），返回 429 + `Retry-After`。
3. 会话有效期改为可配置（默认 12 小时，范围 15 分钟–7 天），并实现空闲超时（每次请求滑动续期，超过空闲时间失效）。租户级配置界面属于 E-80，本任务只做后端参数与默认值。
4. 登录失败锁定时给企业管理员发站内通知（若 T-023 已完成；否则留 TODO 并在看板备注）。

## 验收标准

- [ ] 测试覆盖：第 5 次失败后锁定、锁定期内正确密码也失败、15 分钟后恢复（用可注入时钟）、IP 限流 429。
- [ ] 不泄露账号是否存在（不存在的邮箱也计入 IP 限流，提示文案一致）。
