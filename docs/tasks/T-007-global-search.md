# T-007 全局搜索

**版本**：V0.2　**依赖**：T-020、T-030、T-060、T-070　**PRD**：GLB-020、GLB-087、PER-003

## 目标

顶栏「搜索任何内容...」（⌘K / Ctrl+K）跨模块搜索当前用户有权看到的对象。

## 范围

1. 后端 `GET /api/v1/search?q=`：按分组返回（租户侧：助理、智能体、知识库、能力、渠道、设置项；平台侧：租户、模型、套餐），每组最多 5 条，含跳转路径。
2. 渠道分组在 T-041 完成后由该任务注册提供者。实现方式：每个领域在自己的模块里注册一个搜索提供者 `@search_provider("assistants")`，签名 `(db, membership, q, limit) -> list[SearchHit]`，**必须复用该领域的列表授权**（`scope_filter`、权限点、软删除过滤），不允许另写一套查询绕过授权。匹配用 `ILIKE`（名称、描述、中英文名），不引入搜索引擎。
3. 设置项是静态索引（导航项 + 子项名称，中英双语），按角色过滤（设置只有租户管理员可见，审计员可见的项按 6.1）。
4. 平台侧提供者只对平台管理员生效；租户账号调用平台分组返回空。
5. 前端：顶栏输入框、快捷键、分组下拉、键盘上下选择、回车打开、空结果「无匹配项」、输入 300 ms 防抖（GLB-062）。

## 验收标准

- [ ] 测试：无权限的组织内助理不出现在结果中；跨租户对象不出现；查看者看不到设置分组。
- [ ] 每个提供者都有一条“授权一致性”测试：搜索结果是对应列表接口结果的子集。
- [ ] P95 < 300 ms（1 万对象的测试数据，PostgreSQL 测试中记录耗时）。

## 不在范围

- 全文检索知识库文档内容（那是 RAGFlow 检索，不是导航搜索）。
