# T-027 助理测试控制台与测试用例

**阶段**：3　**依赖**：T-025、T-021　**PRD**：AST-054、AST-071、4.4 TestCase
**外部条件**：供应商 Key（评测判定需要真实模型）

## 范围

1. 详情页右侧实时测试控制台（AST-054）：环境与版本选择（草稿或已发布版本）、流式消息、耗时与点数、重置、“查看完整调用链”跳转 Langfuse trace（有配置时）、“添加为测试用例”。测试对话 `source=debug`，不计入运营统计。
2. 测试用例页签（AST-071）：CRUD、复制、运行单条/运行全部（Worker 批量执行，`source=test`），用租户默认对话模型作为评测模型判定“是否符合期望行为”，保存实际回复与判定理由；状态只能由运行结果写入。
3. 发布（T-024）前自动运行全部用例，结果附在审批单 `checks` 中。

## 验收标准

- [ ] 评测判定逻辑可替换且有单元测试（用假模型）。
- [ ] 运行全部的进度在界面可见，失败原因可见（NFR-020）。
