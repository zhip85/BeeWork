# T-103 平台总览真实指标与区域健康

**版本**：V1.0　**依赖**：T-011、T-102、T-123　**PRD**：3.12.1（PLT-002–004）、GLB-022、8.3#19

## 范围

1. 指标卡（PLT-002）：活跃租户（试用 / 正式 / 宽限，附本月新增）、月收入（本月已出账，附环比）、模型毛利（(点数收入 − 模型成本) / 点数收入，点数收入口径见 T-102 的暂定决策，模型成本取 LiteLLM 花费）、平台可用率（近 30 天，来自 T-123 的探测数据）。
2. 租户健康（PLT-003）：最高配额使用率、健康/告警（配额 ≥ 80%、错误率 > 2%、存在逾期账单任一成立），按风险排序取前 5，点击进入详情。
3. AI 网关卡（PLT-004）：近 24 小时调用总数与成功率、各供应商调用占比与在线状态（来自 T-011 汇总的 LiteLLM 数据与模型连通性检查）。
4. 顶栏区域状态（GLB-022）：各区域健康探测结果，异常时黄/红并显示异常区域数。
5. 替换平台总览中的静态值。

## 验收标准

- [ ] 指标计算单元测试（含无数据时的“—”与环比）。
- [ ] 平台总览接口 P95 < 500 ms（1000 租户测试数据）。
