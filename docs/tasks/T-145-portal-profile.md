# T-145 员工个人中心

**版本**：V0.4　**依赖**：T-142、T-056（个人记忆）；通知项在 T-088 合入后接通　**PRD**：演进 PRD 9.3、11.6

## 范围

1. 个人中心（只从左下角账号菜单进入）：显示名称、职位、部门（只读，来自组织）、默认应用（从可见应用中选）、默认回答风格。存 `portal_profiles`（tenant、membership 一对一）。门户设置关闭“允许编辑个人资料与偏好”时只读，修改接口 403。
2. 个人记忆：门户设置开启时显示——查看记忆条目、关闭个人记忆、删除全部个人记忆（调用 T-056 的“按终端用户删除全部记忆”）。员工关闭后停止写入；管理员关闭时入口消失且服务端停止写入。
3. 任务完成通知：门户设置开启时显示开关；投递通道在 T-088 之前只写站内通知（T-023）。
4. 账号安全：修改密码（本地账号）、当前登录方式说明；退出登录。

## 验收标准

- [ ] 测试：员工只能读写自己的资料；关闭开关后接口 403；删除个人记忆后不再注入（与 T-056 测试共用夹具）。
