# T-145 员工个人中心

**版本**：V0.4　**依赖**：T-142、T-056（个人记忆）；通知项在 T-088 合入后接通　**PRD**：演进 PRD 9.3、11.6

## 范围

1. 个人中心（只从左下角账号菜单进入）：显示名称、职位、部门（只读，来自组织）、默认应用（从可见应用中选）、默认回答风格。存 `portal_profiles`（tenant、membership 一对一）。门户设置关闭“允许编辑个人资料与偏好”时只读，修改接口 403。
2. 个人记忆：门户设置开启时显示——查看记忆条目、关闭个人记忆、删除全部个人记忆（调用 T-056 的“按终端用户删除全部记忆”）。员工关闭后停止写入；管理员关闭时入口消失且服务端停止写入。
3. 任务完成通知：门户设置开启时显示开关；投递通道在 T-088 之前只写站内通知（T-023）。
4. 账号安全：修改密码（本地账号）、当前登录方式说明；退出登录。

## 验收标准

- [ ] 测试：员工只能读写自己的资料；关闭开关后接口 403；删除个人记忆后不再注入（与 T-056 测试共用夹具）。

## 完成记录（2026-11-12，Claude Sonnet 5.5）

**迁移**：`0048_portal_profiles`（可降级）：`portal_profiles`（租户 + 成员唯一；职位、默认应用、个人记忆开关、任务通知开关；没有记录 = 默认值）。

**接口**（`/portal/me/*`，全部挂 `require_portal_seat`，只能操作自己）：`GET/PUT profile`（显示名称、职位、默认应用；部门 / 邮箱只读；默认应用必须是自己可见的应用，否则 404；已下架的默认应用读取时视为未设置；“允许编辑个人资料与偏好”关闭时 PUT 403）、`GET memory` / `PUT memory/settings` / `DELETE memory`（查看条目、员工自己的开关、删除全部个人记忆——调用 T-056a 的 `delete_end_user_memories`，写 `memory.user_deleted` 审计）、`PUT notifications`、`POST password`（修改本地账号密码：校验当前密码；错误尝试按登录失败计数，连续失败会锁定，不能被当作猜密码接口；新密码 ≥ 12 位且不能与旧密码相同；成功后结束该账号其他所有会话、保留当前会话；写审计）。管理员关闭个人记忆 / 任务通知后对应接口 403。

**个人记忆的两个开关与运行时**：管理员开关（门户设置）与员工开关**任一关闭**，服务端都既不写也不读：`extract_conversation_memory` 对门户终端用户先判断（关闭则不抽取、不写入），运行时注入点（`runtime/executor.py` 的 `memory_context`）关闭时返回空；只影响 `channel_type=portal` 的终端用户，其他渠道不受影响。删除后记忆条目不存在，自然不再注入。

**前端**：个人中心 `/portal/profile`（只从账号菜单进入）：基本信息（显示名称、职位、默认应用可编辑，邮箱 / 部门只读；资料编辑被关闭时整体只读并说明）、个人记忆（开关、条目列表、删除全部并二次确认）、任务完成通知开关、账号安全（登录方式说明、修改密码、退出登录）；管理员关闭的块不显示。默认应用用于新对话的预选（优先级：应用库 `?app=` > 默认应用 > 第一个）。中英文齐全。

**验证**：`ruff` 通过；`test_portal_profile`（14 个）通过，并与 `test_portal_chat`、`test_portal_seat_check`、`test_memory`、`test_runtime`、`test_conversations`、`test_portal_seats` 一起回归通过；迁移升降级与 `alembic check` 通过。测试覆盖：资料读写与审计、只能改自己的、默认应用的可见性、开关关闭 403、记忆只看到自己的与删除全部不影响他人、员工开关 / 管理员开关各自停止注入与写入（用真实对话 + 真实抽取服务）、非门户终端用户不受影响、通知开关、修改密码（当前密码错误、过短、与旧相同、成功后其他会话失效而当前会话保留、旧密码不能再登录、审计、连续错误触发锁定）、无席位 403、跨租户 403、CSRF。前端 `tsc` / `lint` / `i18n:check` / `style:check` / `build` 通过；浏览器（开发库员工账号）检查了个人中心、保存资料、错误当前密码的提示、默认应用预选。

**遗留 / 说明**
1. “默认回答风格”**没有做**：与 T-143 相同，运行入口没有回答风格参数，不放假控件。
2. “任务完成通知”只存开关：目前没有产生门户任务完成通知的功能（长任务 / T-088 之后），开关尚未影响任何通知。
3. 显示名称改的是账号（用户）的名字，对该账号在其他租户里也生效。
4. 登录方式目前固定显示“邮箱与密码（本地账号）”；企业身份登录等 T-146。
5. 没有单条记忆删除，只有“删除全部”（按规格）。
6. 未跑全量后端测试（主机负载高）；合并前补跑。
