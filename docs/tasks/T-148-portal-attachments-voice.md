# T-148 员工端附件与语音输入

**版本**：V1.0　**依赖**：T-143、T-121（对象存储与病毒扫描）　**PRD**：演进 PRD 11.5、17.4
**外部条件**：OpenAI API Key（语音转写）

## 模型选型（开发负责人决定，2026-11-10，可逆）

- 默认语音转写模型 **OpenAI `gpt-4o-mini-transcribe`**，经 LiteLLM 的 `/audio/transcriptions` 调用（与对话模型同一网关、同一租户虚拟 Key 计费与限流）；中英文混说准确率够用、单价低、无需自建服务。备选 `gpt-4o-transcribe`（更准、更贵），由平台在模型目录中切换。
- 平台模型目录新增模型类型 `speech_to_text`；租户在“模型与环境”中启用并设默认，门户语音输入使用该默认；未启用时语音入口不显示。
- 中国大陆区域部署需要境内模型时在 T-131 另选（如阿里云 Paraformer / 通义听悟，经 LiteLLM 或适配层），不影响本任务接口。

## 范围

1. 附件：门户设置开启“文件上传”时显示；文件类型白名单、大小上限、病毒扫描（T-121）通过后才能随消息提交；文件按租户与员工隔离存储，随会话保留期清理；运行时作为本轮上下文提供给智能体（解析方式开工时定，不写入知识库）。
2. 语音：门户设置开启“语音输入”时显示麦克风；浏览器录音权限提示；音频经 LiteLLM 调用租户启用的 `speech_to_text` 默认模型转成文字填入输入框，不自动发送；失败可重试。音频不落盘或按最短保留期删除。
3. 关闭开关后上传与转写接口 403。

## 验收标准

- [ ] 测试：超限 / 非白名单 / 扫描未通过的文件被拒；开关关闭后 403；他人附件不可读。
