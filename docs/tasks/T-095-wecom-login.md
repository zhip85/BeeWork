# T-095 企业微信登录与通讯录同步

**版本**：V1.0　**依赖**：T-091　**PRD**：演进 PRD 12.1、12.4；原型“登录与身份 → 企业微信”
**外部条件**：企业微信测试企业（Corp ID、自建应用 AgentId 与 Secret）

## 范围

1. 身份提供方类型 `wecom`（复用 T-091 的身份提供方模型）：Corp ID、AgentId、Secret（加密存储，响应只返回掩码，支持“更换”）。
2. 扫码登录（网页授权 / 扫码 OAuth）：state 防 CSRF，服务端换取用户身份，按企业微信 userid / 邮箱匹配成员；首次登录自动创建规则同 T-091。
3. 通讯录同步（可选开关）：部门 → 组织、成员姓名与状态；手动同步 + 定时同步（Worker，幂等）；离职成员暂停并吊销会话。
4. 所有出站调用经 T-071 出口执行器或同等的出站校验；配置变更与登录写审计。

## 验收标准

- [ ] 契约测试（`httpx.MockTransport`）：获取 access_token、code 换身份、部门 / 成员拉取、错误码映射；state 不符被拒。
- [ ] 有测试企业时跑通一次真实扫码登录，记录在 development-status。
