# T-043 Widget 模板、租户组件库与组件编辑器

**版本**：V0.3　**依赖**：T-041　**PRD**：3.7.6（CHN-040–046）、3.15.2（PLT-110–114）、5.1 组件状态机、RUL-013、NFR-009（组件渲染转义）、NFR-016

## 范围

1. 平台模板 `widget_templates`（名称中英、类型 Card/Comparison/Timeline/Form、描述、触发标签、schema、模拟数据、兼容矩阵（5 渠道 × native/text/json/off）、版本、状态 已发布/草稿/已弃用）；schema、触发标签或兼容矩阵变化时强制递增版本（PLT-112）；有租户副本时只能弃用不能删除。预置 4 个模板（PLT-114）。
2. 租户组件 `tenant_components`（同上字段 + 来源模板 ID 与已安装版本 + 状态 启用/草稿/停用）；触发标签租户内唯一、自动规范化；保存自动递增小版本；被已发布渠道快照使用的组件不可删除（RUL-013）。
3. 复制与同步（CHN-043–044）：复制模板为租户组件；模板有新版本时显示“模板已更新 vX”，同步前展示差异确认，保留租户名称与描述。新租户开通时自动复制前三个模板（PLT-114，由 T-100 开通流程调用，先提供服务函数）。
4. Schema：支持 PRD 的简化字段描述（`name?`、`string[]`、`{label: string; url: string}[]`）与标准 JSON Schema；`parse_component_schema()` 与 `validate_component_payload()` 供 T-059 与发布试跑使用。
5. 编辑器（CHN-045，平台与租户共用一个组件）与内置渲染器（CHN-046）：React 组件，渲染数据一律转义，键盘可操作（回车/空格打开卡片）；同一渲染器打包进网站/H5 SDK。
6. 渠道向导第 2 步的组件选择接入（CHN-011），只列兼容且非停用的组件。

## 验收标准

- [ ] 简化 schema 解析器与校验器单元测试（可选字段、数组、嵌套对象、类型不符）。
- [ ] 测试：XSS 载荷在渲染器中被转义（前端测试）；被快照使用的组件删除 409；模板弃用后不可新复制。
